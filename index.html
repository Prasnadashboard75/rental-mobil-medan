⚙️ Panel Admin

Gunakan format internasional tanpa "+" dan tanpa "0" di depan. Contoh: 081234567890 → 6281234567890. Semua pesanan pelanggan masuk ke nomor ini.

🖼️ Latar contoh aktif — masuk Admin untuk mengganti

Hanya admin yang bisa mengganti latar ini. Pilih foto lebar (mis. showroom, garasi, jalan raya malam) — otomatis dikompres agar website tetap ringan. Klik Simpan Pengaturan setelah memilih, lalu terbitkan lewat tombol Publitasi agar terlihat oleh pelanggan.

🚀 Menerbitkan / memperbarui katalog online (GitHub Pages / Netlify):
1) Atur armada, harga, status & nomor WhatsApp di tab Armada dan Pengaturan.
2) Klik tombol di bawah — file index.html berisi data terbaru Anda akan terunduh.
3) Unggah file itu ke GitHub (Tambahkan file → Unggah file → Komit perubahan). Website pelanggan otomatis ikut terbaru dalam ±1 menit.
4) Ulangi langkah 1–3 setiap kali ada perubahan.
Cara kerja data di perangkat ini: armada & pengaturan tersimpan otomatis di penyimpanan lokal (localStorage) perangkat ini. Untuk cadangan atau pindah perangkat, gunakan Ekspor lalu Impor. Agar perubahan terlihat oleh semua pengunjung, gunakan tombol Publikasikan di atas lalu unggah ulang ke GitHub.
Hosting gratis pilihan: GitHub Pages (panduan tersedia), Netlify Drop (drag & drop, paling cepat), atau Vercel. Semuanya gratis untuk katalog seperti ini.
